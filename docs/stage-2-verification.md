Дата: 04.11.2026. Статус: реализован, локальная версия обновлена, ожидает пользовательской приёмки. Этап 3 не начат.

## Результат

Добавлены вложенные заготовки и их выход, упаковка, анализ скидки, общие и индивидуальные пороги, цветовые зоны, минимальная отпускная цена. Изменения заготовок показывают затронутые заготовки и блюда до применения. Все подтверждённые доменные изменения проходят прежние транзакционные команды с журналом, ревизиями и защитой от повторного применения.

Клиентский JavaScript преобразует только количества при смене совместимых единиц и управляет формой. Денежные расчёты выполняются сервером. При отключённом JavaScript преобразование единиц выполняет сервер; повторный предпросмотр не преобразует значение второй раз.

## Сопоставление с критериями

| Требование | Проверка |
| --- | --- |
| 04: выход заготовки | 3000 ₸ / 2 кг × 100 г = 150 ₸; выход 1,5 кг → 200 ₸; предпросмотр, применение и зависимые рецептуры |
| 05: вложенность и повторный ингредиент | 600 → 720 ₸, вклад по путям 20 + 40 + 60; потери 20% → 750 ₸; цикл отклоняется без частичного сохранения |
| 06: упаковка | 500 шт. за 25000/30000 ₸: блюдо 650/660 ₸; потери и включение в заготовку отклоняются |
| 07: округление | Три строки 10,004 → итог 30,01; промежуточные 0,055 отображаются 0,06, но две единицы дают 0,11 |
| 08–09: скидка и зоны | P=333,33, d=10%, C=120 → P_eff=300,00, r=40%; точные границы 400/400,01 и 600/600,01; нулевая P_eff; пороги выше 100% |
| 10: минимальная цена | 333,33 и 1944,44; предыдущий шаг 0,01 не проходит; самостоятельный перебор на Decimal для малых примеров |
| Наследование порогов | Прямой конфликт отклоняется; конфликт после общей настройки сохраняется без цвета и P_min; C и r остаются; возврат к общему порогу восстанавливает состояние |
| Сохранность | Откат при ошибке аудита, устаревшая форма, повторное подтверждение, сохранение после предпросмотра, несогласованные единицы |

Ожидаемые суммы заданы буквальными значениями из критериев. Дополнительный перебор минимальной цены использует отдельный алгоритм Decimal/quantize, не production-функции money или бинарного поиска. Независимый расчётный рецензент сопоставил ещё 1000 случаев с отдельной точной формулой.
