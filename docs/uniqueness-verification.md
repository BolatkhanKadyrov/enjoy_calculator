# Уникальность блюда и общая основа интерфейса — 0.3.1

## Подтверждённое правило

04.11.2026 заказчик подтвердил подсчёт разных видов сырья через все вложенные заготовки, без упаковки. Идентичность определяется UUID, повтор одного ингредиента считается один раз. Сравнение выполняется со всеми сохранёнными блюдами, даже если другие блюда скрыты фильтром или находятся на следующей странице. Количество, стоимость, потери и скидка не участвуют.

В списке «Уникальность» расположена между «Со скидкой» и «Доля». Карточка показывает процент и отношение X/Y. Непосредственное уникальное сырьё помечено «Только в этом блюде». В строке заготовки раскрывается список её сырья с такими же индивидуальными пометками; сама заготовка не объявляется уникальным ингредиентом. Отсутствие сырья выводится как «—» и `0/0`. Для дробного процента используется округление half-up до двух знаков только при отображении, с меткой `~`; исходные множества и дробь остаются точными.

## Реализация и сохранность

`tseh/services/uniqueness.py` строит отдельную модель чтения. Пять массовых запросов загружают составы и виды позиций, топологический обход раскрывает заготовки, индекс использования считает блюда для каждого UUID сырья. Расчёт не обращается к финансовому ядру. Цикл в повреждённых данных вызывает явную ошибку, не частичный показатель.

Страницы вызывают модель чтения в существующем согласованном снимке. Миграций, новых записей, изменений финансовых формул, текущих цен, ревизии и журнала нет. Рабочие данные не используются как тестовые фикстуры.

## Независимые эталоны и проверки

Ожидаемые значения заданы в тестах буквально, без вызова проверяемого алгоритма для формирования ответа:

| Сценарий | Ожидаемый результат |
| --- | --- |
| Первое блюдо A,B,C,D; второе C,D | Первое: 2/4, 50%; второе: 0/2, 0% |
| Единственное блюдо с сырьём | 100% |
| Повтор напрямую и через две вложенные заготовки | Один вид сырья в знаменателе |
| Сырьё с нулевой ценой | Участвует в подсчёте |
| Одинаковые названия, разные UUID | Разные виды сырья |
| Только упаковка | 0/0, процент отсутствует |
| Добавление сырья в другое блюдо | Показатель первого блюда уменьшается при следующем чтении |
| Фильтр скрывает остальные блюда; список содержит 31 блюдо | Сравнение по всей базе, независимо от страницы |
| Карточка: вложенная начинка, сырьё, бесплатная соль, упаковка | Стоимость остаётся 115 ₸; уникальность 2/3; пометки только у сырья |

Полный серверный прогон: **243 теста прошли за 44,99 с**, в отдельной тестовой PostgreSQL-базе. Среди них 11 новых проверок модели чтения и её интеграции в страницы. Django `check` не выдал замечаний; `makemigrations --check --dry-run` подтвердил отсутствие миграций.

Проверки через Node прошли: 16 проверок точного перевода единиц, 17 сценариев контроллера единиц, 10 групп хранилища черновика, 20 сценариев редактора черновика и 11 сценариев поиска компонентов. Контроллеры проверяются на модели DOM; это не браузерная приёмка.

Независимый агент проверил семантику подсчёта, область сравнения, индивидуальные метки, порядок колонок и отсутствие изменений денежных расчётов/записей; подтверждённых ошибок не выявлено. При интеграционном ревью исправлен CSS-селектор, который уменьшал размер округлённого процента из-за вложенных `span`.

## Визуальная приёмка

Нормы интерфейса — в корневом `DESIGN.md`; контекст продукта — в `PRODUCT.md`. Общие кнопки используют отдельную SVG-иконку, равные отступы, единую высоту и типографику. Категории компонентов имеют жирные заголовки на отдельной подложке. Обновлены общие размеры полей, фокус, состояния и типографика. Статический анализ первоначально обнаружил остаточные размеры и неполную документацию палитры; они отдельно рассмотрены при доведении общей основы.

Попытка подключиться к локальной странице через браузерный инструмент вернула `The browser access host is unavailable`. Визуальный прогон не выполнен. До закрытия пользовательской приёмки остаются проверки на реальном экране:

- Список блюд: порядок колонок, длинные названия, кнопка «Новое блюдо», горизонтальная прокрутка на узком экране.
- Редактор: две категории, прокрутка меню, длинные варианты, клавиатурный выбор, новый компонент и сохранение черновика при F5.
- Карточка: 50%, дробный процент, 0/0, непосредственное и вложенное сырьё, раскрытие с клавиатуры.
- Общие элементы: hover/focus/disabled/error, ширины 360/760/1100 px и увеличение текста до 200%.

Эта правка не означает завершения этапов 4–7 или пользовательской визуальной приёмки.

Финальная статическая проверка: Impeccable выдал 29 advisory-замечаний (22 о цветах, 6 о размерах шрифта, 1 о радиусе), без замечаний остальных уровней. В их числе неподключённый через Django static-тег CSS в анализе сырых шаблонов и сохранённые декоративные параметры бренда; скан не объявляется чистым и не подменяет браузер. Все буквальные размеры текста менее 13 px в CSS устранены; JSON дизайн-системы корректен, CSS-токены определены. Финальные статические файлы собраны, локальный сервер перезапущен, `/health/` подтвердил готовность.
